# Towards-Mutagenesis-Of-All-Human-Disease-Genes
Master Dissertation

Master's dissertation project, Human Domainome Project, CRG Barcelona (June–Dec 2025), under Dr. Antoni Beltran and Dr. Ben Lehner.

## Overview
This project contributes to a large-scale effort to functionally characterize variants across human disease-gene protein domains using deep mutational scanning (DMS). Work covered:
- Improving plasmid assembly workflows for high-throughput variant libraries in *S. cerevisiae*
- Processing DMS sequencing data with the [DiMSum](https://github.com/lehner-lab/DiMSum) pipeline in R
- Screening ~4,000 protein domains (~80,000 variants) via DHFR-methotrexate selection to score variant fitness effects
